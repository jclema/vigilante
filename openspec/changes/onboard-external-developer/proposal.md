## Why

An English-speaking external developer may join the project. The repo needs a
clear onboarding path that explains product scope, current state, access
boundaries, SDD workflow, and a safe first contribution without relying on
verbal context.

## What Changes

- Add English onboarding docs for external contributors.
- Define a first-week plan and access policy.
- Provide a safe first-contribution brief.
- Capture onboarding behavior in OpenSpec.
- Keep runtime behavior unchanged.

## Capabilities

### New Capabilities

- `external-contributor-onboarding`: Developer onboarding, access, and first contribution expectations.

### Modified Capabilities

- None. This change is documentation and process only.

## Impact

- Adds `docs/onboarding/` documentation.
- Adds OpenSpec artifacts for onboarding.
- No application code, production dependency, infrastructure, schema, or secret changes.
