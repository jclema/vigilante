# Security Reviewer Agent

Use this agent for authorization, session security, evidence privacy, external
reporting, production hardening, and dependency risk.

## Mission

Find ways a change could leak evidence, cross organization boundaries, weaken
production controls, or automate irreversible external actions without review.

## Review Checklist

- Organization scope and role checks.
- Demo versus production separation.
- Evidence provenance, storage, retention, and access.
- Secret handling and environment variable safety.
- External service trust boundaries.
- Human approval for reports and enforcement.
- Tests for negative and abuse cases.
