# Adversarial Product Review

Use before shipping high-risk changes or committing to product direction.

## Review Lens

- Does the change create measurable value for operators, networks, or dealers?
- Is the evidence reliable enough for the recommended action?
- Could the workflow create false confidence or false positives?
- Could a user cross organization boundaries?
- Could automation trigger reporting or enforcement without review?
- What happens when Google APIs, browser automation, Maps pages, or
  notifications fail?
- Is the fastest useful version smaller than the proposed version?

Return prioritized findings with concrete fixes.
