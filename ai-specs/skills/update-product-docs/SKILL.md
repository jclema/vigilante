# Update Product Docs

Use when a change affects setup, operations, environment variables, user
workflows, external integrations, or product positioning.

## Rules

- Update the narrowest canonical doc.
- Link instead of duplicating long context.
- Keep `AGENTS.md` short.
- Update `openspec/` before code when behavior changes.
- Update runbooks with exact commands for production operations.
